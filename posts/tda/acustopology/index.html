This is hard to explain, at least from an epistemological point of view. Lets say I needed an excuse to dig deeper into a subject that bugged me for the last five months.

Topological Data Analysis (TDA), as I’ve come to understand it, is the belief that data can hold some internal geometric structure that can be exploited through topologist-single-blade-swiss-army-knife homology.

Don’t blame me for the following rant, blame yourself.

The rough idea¶

So the idea is straightforward:

  1. Take any audio file; convert it into its spectrogram.
  2. Take the spectrogram and convert it into a point cloud.
  3. Take the point cloud and compute its Vietoris-Rips complex.

There are several flows already.

First of all, how the heck TDA works?¶

Nice and simple. You have your favorite point cloud, right?

Then all you need to do is to grow (hyper-)spheres around them. This is, of course, tailored to the dimensionality of your dataset and the distance you impose on the surrounding space.

    import librosa
import librosa.display
import matplotlib.pyplot as plt

from scipy.io.wavfile import write
import numpy as np

# import audio file

# Assuming you have your audio loaded in `y` and its sampling rate in `sr`
S = librosa.feature.melspectrogram(y=y, sr=sr, n_fft=2048, hop_length=512, n_mels=128)
S_dB = librosa.power_to_db(S, ref=np.max)

# Generate the time and Mel frequency axes
times = librosa.times_like(S, sr=sr, hop_length=512)
mel_freqs = librosa.mel_frequencies(n_mels=128, fmin=0, fmax=sr/2)

# Prepare x (time), y (frequency), and z (intensity) for 3D plotting
x = np.tile(times, len(mel_freqs))
y = np.repeat(mel_freqs, len(times))
z = S_dB.flatten()

# Plotting
fig = plt.figure(figsize=(10, 7))
ax = fig.add_subplot(111, projection='3d')

# Scatter plot for the 3D point cloud
scat = ax.scatter(x, y, z, c=z, cmap='viridis', s=1)

# Adding labels and title
ax.set_xlabel('Time (s)')
ax.set_ylabel('Frequency (Hz)')
ax.set_zlabel('Intensity (dB)')
ax.set_title('3D Point Cloud of Mel Spectrogram')

# Add a color bar to indicate the intensity values
cbar = fig.colorbar(scat, ax=ax)
cbar.set_label('Intensity (dB)')

# Define the downsample by averaging function

def downsample_by_averaging(points, cube_size):
    min_coords = np.min(points, axis=0)
    max_coords = np.max(points, axis=0)
    indices = np.floor((points - min_coords) / cube_size).astype(int)
    dtype = [('sum', float, 3), ('count', int)]
    grid = np.zeros(indices.max(axis=0) + 1, dtype=dtype)
    for point, index in zip(points, indices):
        grid[tuple(index)]['sum'] += point
        grid[tuple(index)]['count'] += 1
    non_empty_cubes = grid['count'] > 0
    averaged_points = grid['sum'][non_empty_cubes] / grid['count'][non_empty_cubes][:, np.newaxis]
    return averaged_points

FAQ¶

Why does the spectrogram of an audio file capture its essence?¶

It doesn’t. In my opinion is just an interesting perspective you can take. Besides, it actually simplify a lot the next step.

Wait, but what are spectrograms?¶

TLDW: Spectrograms are the representation in (aplitude, frequency, time)—space of sound.

They encompass so much information about the sound. The key is that by taking only the notes you are basically throwing away all the information about the timbre, i.e. you are effectively restricting to the first Fourier coefficient and silencing to zero every other one.

But Fourier is nice, we want everything. Hence, the Topological Audio-Data Analysis ( TADA! )

Euclidean distance doesn’t capture any “musical” information¶

\(C_{0}\) is musically, perceivably, “closer” to its harmonics than \(D_{0}\), i.e.

\[[C_0, C_1, G_1, C_2, E_2, G_2]\] are the pitches of the first six harmonics in the equal temperament tuning system.

or pedantically the first five overtones: \[[C_1, G_1, C_2, E_2, G_2]\]

and overtones do not have overtones, i.e. are f sine waves. And why is that is f beautiful and Fourier-pilled

What does the information about this “topology” tells about the audio¶

Honestly, I don’t know. But this can be a way to classify the data coming from an audio file. Thinking not that hard about it, you could imagine that no matter the significance of the topological information retrieved in this way, still on a meta-analysis you could find patterns inside classes of similar audio file.
